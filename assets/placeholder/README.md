# Placeholder presentation assets

The current game table deliberately uses Godot controls, colors, text, and simple geometry.
Named scene regions (`TopSeat`, `LeftSeat`, `RightSeat`, `BottomSeat`, `Piles`, and `Hand`)
are stable replacement points for final card art, table artwork, effects, and animation work.

The placeholder palette is functional UI, not a commitment to the final visual theme.
