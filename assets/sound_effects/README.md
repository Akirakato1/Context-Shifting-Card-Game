# Sound effects

Zeitklus includes the cues it uses from **Card Game SFX Lite** by Willosuna, plus three original WAVs for the countdown and phase sign chains. The short invalid-action buzz is synthesized in the game. The Willosuna clips are included for use in Zeitklus under their [pack license](Card%20Game%20SFX%20Lite%20%28Free%29/LICENSE.txt). [Original pack](https://willosuna.itch.io/card-game-sfx-lite)

The optional **Tabletop Games Sound Effect Pack** by JDSherbert supplies five alternate cues. Its license restricts sharing raw audio in source repositories. Drop the following files into the ignored `Tabletop Games SFX Pack/` directory to enable them in a local build. The game uses bundled card sounds for these cues when the optional files are absent. [Original pack](https://jdsherbert.itch.io/tabletop-games-sfx-pack) · [Creator’s terms](https://jdsherbert.itch.io/terms-and-conditions)

Each filename begins with `JDSherbert - Tabletop Games SFX Pack - `.

- `Deck Deal - 2.wav`
- `Dice Pickup - 2.wav`
- `Piece Impact - 1.wav`
- `Piece Impact - 2.wav`
- `Piece Move - 2.wav`
